Hardware Classification & Metal GPU Engine

Engineered natively in C++ using macOS Quartz Event Services, IOKit HID, and Metal API to classify pointing hardware and graphics processors.

🖱️

Hardware Input Classifier

Differentiates clicks originating from an External Physical Mouse versus an Integrated/Magic Trackpad using two synchronized layers:

Event Tap Subtype kCGMouseEventSubtype: 3 (Touch) vs 0 (Mouse)
IOKit HID Manager Generic Desktop 0x02 (Mouse) vs 0x05 (TouchPad)
Device Name Heuristic "Apple Internal Keyboard / Trackpad"

Metal API GPU Enumerator

Enumerates all graphics devices via MTLCopyAllDevices() to distinguish Integrated (iGPU), Discrete (dGPU), and External (eGPU) processors.

Apple Silicon (M1/M2/M3/M4) Single Unified SoC GPU → Integrated (iGPU)
Intel Macs (Dual-GPU) Intel Iris (isLowPower=true) + AMD Radeon (dGPU)
Thunderbolt eGPU External Enclosure → isRemovable=true

Architectural Data Pipeline & Struct Alignment

64-bit memory layout matched byte-for-byte across the native C++ library and managed C# P/Invoke boundary.

1
Mouse Click Tap
CGEventTapCreate listens system-wide on dedicated background thread.
→
2
Hardware Classifier
IOKit HID & Subtype tags click as Trackpad or External Mouse.
→
3
Screen Capture
ScreenCaptureKit grabs full display into raw BGRA buffer.
→
4
P/Invoke Bridge
Function pointer callback invokes C# orchestrator with SkanCapture.
→
5
In-Memory OCR
Pipes PNG bytes via stdin to extract word bounds with zero temp files.
→
6
Mask & Compare
Redacts PII, generates side-by-side composite and JSON audit report.

SkanCapture 64-Bit Memory Layout (56 Bytes)

Offset Field Type Size Purpose
0x00 Width int32 4 bytes Screen horizontal pixel count
0x04 Height int32 4 bytes Screen vertical pixel count
0x08 Stride int32 4 bytes Bytes per row (aligned to row boundaries)
0x0C [Padding] pad 4 bytes Aligns 64-bit pointer to 8-byte boundary
0x10 PixelData uint8_t* / IntPtr 8 bytes Raw BGRA pixel buffer pointer
0x18 InputSource int32 4 bytes 1 = External Mouse, 2 = Trackpad
0x1C [Padding] pad 4 bytes Aligns double precision float to 8-byte boundary
0x20 ClickX double 8 bytes Horizontal screen coordinate of user click
0x28 ClickY double 8 bytes Vertical screen coordinate of user click
0x30 TimestampMs int64 8 bytes Unix epoch milliseconds timestamp
